# Elit Klima – Нашият дом

Сайт компании «Нашият дом – ЕлитКлима ЕООД»: продажа, монтаж и обслуживание кондиционеров по Южному Черноморью.

Чистый HTML/CSS/JS — без сборки. Открыть `index.html` в браузере или включить GitHub Pages (Settings → Pages → Branch: `main`, папка `/root`).

## Структура

```
index.html            – разметка всех секций
assets/css/style.css  – стили (цвета логотипа в :root)
assets/js/data.js     – ДАННЫЕ: услуги, товары, населённые пункты
assets/js/main.js     – логика (каталог, фильтры, калькулятор, формы, меню)
assets/img/           – логотип, флаер; сюда же кладите фото товаров
```

## Формат сайта

Сайт — **корпоративный каталог с заявками**, а не интернет-магазин: нет корзины, оформления заказа, доставки и оплаты. На карточках вместо «Купить» — «Запитване за цена» и «Консултация». Обе кнопки открывают форму заявки, которая отправляется в WhatsApp или на e-mail. Цены на сайте не публикуются: у всех моделей и услуг стоит «По договаряне», пояснение — под каталогом и в футере.

## Языки

Основной язык — болгарский, на выбор EN и RU (переключатель в верхней полосе, выбор запоминается; ссылка вида `?lang=ru` открывает нужный язык).
Все тексты интерфейса — в `assets/js/i18n.js`. Описания товаров собираются автоматически из характеристик на трёх языках.

## Как добавить / изменить товар

Откройте `assets/js/data.js` → массив `products` (одна строка — одна модель):

```js
{"id": "daikin-ftxm25", "brand": "Daikin", "name": "Daikin Perfera FTXM25R", "type": "wall", "btu": 9000,
 "area": 25, "energy": "A+++", "wifi": true, "image": "assets/img/products/daikin-ftxm25.webp",
 "badges": ["hyper"], "specs": {"refrigerant": "R32", "noise": 19, "heatMin": -20, "seer": 8.6, "scop": 5.1, "warranty": 36}}
```

- `type`: wall | floor | multi | cassette | duct | column | mobile
- `badges`: `leader` (лидер продаж), `hyper` (гиперинвертор), `new` (новинка), `install` (монтаж включён) или любой свой текст
- `featured: true` — модель показывается первой (сейчас так помечен Hyundai Winterpack)
- `description` — необязательно: свой текст (строка или `{bg, en, ru}`), иначе описание генерируется

Сейчас в каталоге 101 модель. Фото — в `assets/img/products/<id>.webp`.

## Галерея выполненных работ

Положите фото в `assets/img/gallery/` и добавьте их в массив `gallery` в `data.js`:

```js
gallery: [
  { image: "assets/img/gallery/obekt-1.jpg",
    title: { bg: "Монтаж на стенен климатик", en: "Wall unit installation", ru: "Монтаж настенного кондиционера" },
    place: "гр. Несебър" }
]
```

Пока массив пустой, вместо галереи показывается блок со ссылкой на TikTok. Первое фото выводится крупно.

Услуги (`services`) и населённые пункты (`towns`) редактируются там же.
